Privacy Policy

Last updated: August 2026

1. Information We Collect

When you use the Social Media Bot, we collect:

  • Telegram User ID — To identify your account and link social media connections.
  • OAuth Tokens — Encrypted access tokens for X, TikTok, and Instagram, used solely to post content on your behalf.
  • Post Content — Text and media you send through the bot, processed temporarily and not stored after posting.

2. How We Use Your Information

Your data is used exclusively to:

  • Authenticate you with connected social media platforms.
  • Post content you submit to your selected social media accounts.
  • Display your connected account status within the Telegram bot.

We do not use your data for advertising, analytics, or any purpose beyond the core functionality of the bot.

3. Data Storage & Security

All OAuth tokens are encrypted at rest using AES-256 encryption. The database is hosted on Supabase (PostgreSQL) with industry-standard security. Your data is never shared with third parties.

4. Data Retention

Your Telegram ID and connected account tokens are stored as long as your account remains active. You can delete all your data at any time by using the /disconnect command for each platform. Media files are processed in memory and never stored to disk.

5. Third-Party Services

This bot integrates with the following third-party platforms via their official APIs:

  • X (Twitter) API
  • TikTok Content Posting API
  • Instagram Graph API (via Facebook)
  • Telegram Bot API

Each platform's use of your data is governed by their respective privacy policies.

6. Your Rights

You have the right to:

  • Know what data we store about you.
  • Request deletion of your data at any time.
  • Disconnect any or all social media accounts.

7. Contact

For privacy questions, message the bot using /help on Telegram.
